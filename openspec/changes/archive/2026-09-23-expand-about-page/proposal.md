## Why

The About page only lists four one-line feature blurbs. A visitor cannot tell who made Mundus, where it comes from, or what each page can actually do.

## What Changes

- Add a short project introduction and a "who made it" note (author and location).
- Replace the one-line blurbs with one section per page (Map, Dungeons, Planet, System, Dice), each listing the features available there and linking to the page.
- Add a note that every page works on phones and tablets.
